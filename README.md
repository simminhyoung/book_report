# 독후감 나눔

이메일/비밀번호로 로그인해서 나만의 독후감을 기록하고, 원하는 글만 골라
공개하거나 비공개로 둘 수 있는 웹 앱입니다. `/explore` 페이지에서는 다른
사람들이 공개한 독후감을 검색·필터링하며 읽고, 좋아요와 댓글을 남길 수
있어요. (Claude Design 리디자인 시안을 기반으로 리뉴얼했습니다.)

## 기술 스택

- **Next.js 14** (App Router, Server Actions) — 프론트엔드 + 백엔드를 한
  프로젝트에서 처리
- **Prisma + PostgreSQL** — Render에 만든 Postgres 데이터베이스를 사용해요
- **bcryptjs** — 비밀번호 해시
- 세션은 자체 구현 (DB에 세션 토큰을 저장하고, httpOnly 쿠키로 관리)
- Noto Serif KR / Noto Sans KR (Google Fonts)

## 검색엔진 노출(SEO)

- `/robots.txt`, `/sitemap.xml`을 자동 생성해요(`app/robots.js`, `app/sitemap.js`).
  사이트맵에는 공개(`isPublic: true`)로 설정된 독후감만 포함돼요.
- `/my`, `/my/write`, `/my/[id]/edit`, `/login`, `/signup`처럼 로그인해야
  볼 수 있는 페이지는 `robots: { index: false }`로 검색엔진이 색인하지
  않도록 막아뒀어요.
- 독후감 상세 페이지(`/explore/[id]`)는 책 제목·한 줄 총평을 페이지 제목/설명
  으로 자동 사용해서, 검색 결과에 책별로 따로 노출될 수 있어요.
- 도메인을 커스텀 도메인으로 바꾸면 `SITE_URL` 환경 변수만 새 주소로
  바꿔주면 메타데이터·사이트맵이 자동으로 맞춰져요 (기본값은 현재 Render
  주소예요).

이것만으로 자동으로 검색에 뜨지는 않고, 아래를 직접 해주셔야 실제로
색인이 시작돼요.

1. **Google Search Console** (https://search.google.com/search-console) 에서
   속성 추가 → `https://dokhoogam-app.onrender.com` 입력 → "HTML 태그" 방식으로
   소유 확인 → 받은 `<meta name="google-site-verification" ...>` 코드를
   알려주시면 제가 `app/layout.js`에 넣어드릴게요 → 등록 후 "사이트맵 제출"에서
   `sitemap.xml` 제출.
2. **네이버 서치어드바이저** (https://searchadvisor.naver.com) 도 같은 방식으로
   사이트 등록 + 소유 확인 + 사이트맵 제출을 해두면 네이버 검색에도 노출돼요.
3. 등록 후 실제 검색 결과에 뜨기까지 보통 며칠~몇 주 걸려요. 즉시 되는 건
   아니라는 점 참고해주세요.

## 주요 화면

| 경로 | 설명 |
|---|---|
| `/` | 랜딩 페이지 — "나에게 해주고 싶은 말" 소개, 3단계 흐름 |
| `/signup`, `/login` | 회원가입 / 로그인 |
| `/my` | 내가 쓴 독후감 카드 그리드 (전체/공개/비공개 탭, 왼쪽엔 홈·통계·과거의 내가 보내는 말 탭 + 기록 현황) |
| `/my/[id]` | 내 독후감 상세 (수정·삭제·공개 전환, 나에게 해주고 싶은 말 + 답장 기록) |
| `/my/write` | 새 독후감 작성 (책 정보 → 총평 → 본문, 장르·별점 선택형, 실시간 작성 상태) |
| `/my/[id]/edit` | 독후감 수정 |
| `/my/stats` | 독서 통계 — 받은 하트, 가장 많이 받은 글, 월별 기록, 장르 분포 |
| `/my/past` | 과거의 내가 보내는 말 — 예전에 남긴 "나에게 해주고 싶은 말"을 무작위로 다시 보여주고, 오늘의 나로서 답장을 남길 수 있어요 |
| `/explore` | 공개 독후감 둘러보기 — 검색, 장르/별점 필터, 정렬(최신·좋아요·댓글) |
| `/explore/[id]` | 공개 독후감 상세 — 좋아요, 댓글, 같은 장르 추천 |

### 이번 리뉴얼(2차 리디자인)에서 새로 생긴 기능

- **나에게 해주고 싶은 말** — 독후감을 쓸 때 미래의 나에게 남기는 한마디를
  따로 적어둘 수 있어요.
- **과거의 내가 보내는 말** (`/my/past`) — 예전에 남긴 말 중 하나를 무작위로
  다시 보여주고, "오늘의 나"로서 답장을 남기면 그 독후감 아래에 함께
  쌓여요. 아직 아무 글에도 이 문장을 남기지 않았다면 안내만 보여줘요.
- **내 독후감 상세 페이지** (`/my/[id]`) — 지금까지는 내 독후감을 클릭해도
  볼 곳이 없었는데, 이제 공개/비공개 상관없이 전용 상세 페이지가 생겼어요.
  둘러보기 상세 페이지와 비슷한 구성에 수정·삭제·공개 전환 버튼이 함께 있어요.
- **독서 통계** (`/my/stats`) — 공개한 글에 쌓인 하트 총합, 가장 많이 받은
  글, 글당 평균, 최근 6개월 월별 기록 수, 장르 분포를 보여줘요.
- **왼쪽 사이드바** — `/my`, `/my/stats`, `/my/past`, `/my/[id]`에서 홈/통계/
  과거의 내가 보내는 말 탭과 기록 현황(기록 수·공개·비공개·평균 별점) 요약을
  항상 볼 수 있어요.
- 글쓰기 화면의 **실시간 작성 상태** — 필수 3항목(책 제목·별점·한 줄 총평)
  완료 여부와 본문 4칸 중 몇 칸을 채웠는지를 입력하는 대로 보여줘요. (이전에
  시안에 있었지만 넣지 않았던 "자동 저장됨" 같은 가짜 문구는 넣지 않고,
  실제 입력 상태만 반영하도록 만들었어요.)
- 한 줄 총평 입력 글자 수 실시간 카운터 (60자 제한)

### 리디자인(1차)에서 생긴 기능 (계속 유지)

- 독후감 **좋아요**·**댓글** (로그인한 사용자만 가능)
- 둘러보기 장르/별점 필터 + 정렬(최신순 · 좋아요순 · 댓글순)
- 상세 페이지의 "같은 장르 추천" 사이드바
- 글쓰기 폼의 장르 단일 선택 칩, 별점 클릭 선택 UI

### 시안에는 있었지만 이번에도 넣지 않은 것

- 그리드/목록 보기 전환 (그리드만 유지했어요)

### 책 표지 자동 검색 (카카오 책 검색 API)

글쓰기 화면에서 책 제목으로 검색하면 카카오 책 검색 API로 후보 표지를
보여주고, 클릭 한 번으로 선택할 수 있어요. 선택한 표지는 내 독후감 목록·
둘러보기·상세 페이지에 모두 반영됩니다.

이 기능을 쓰려면 카카오 REST API 키가 필요해요.

1. https://developers.kakao.com 에서 카카오 계정으로 로그인
2. "내 애플리케이션" → "애플리케이션 추가하기"로 앱 하나 생성 (이름은 아무거나)
3. 생성된 앱 요약 정보에서 **REST API 키**를 복사
4. 로컬에서는 `.env`의 `KAKAO_API_KEY`에 붙여넣고, 배포 환경(Render)에서는
   같은 이름의 환경 변수로 등록

API 키가 없어도 앱은 정상적으로 동작해요 — 표지 검색 결과만 안 나오고
자리표시자 패턴이 대신 보여요.

## 배포 (Render)

이 프로젝트는 Render(https://render.com)에 배포하도록 구성되어 있어요.

1. 이 폴더 전체를 GitHub 저장소에 올려주세요 (repo 루트에 `package.json`이
   바로 보여야 해요).
2. Render의 Postgres 인스턴스를 하나 만들고, "External Database URL"을
   복사해두세요.
3. Render에서 Web Service를 만들 때:
   - **Build Command**: `npm install && npx prisma db push --accept-data-loss && npm run build`
   - **Start Command**: `npm run start`
   - **환경 변수**: `DATABASE_URL` = 위에서 복사한 Postgres 연결 문자열,
     `NODE_ENV` = `production`

## 로컬에서 실행하기

이 프로젝트는 `node_modules`가 포함되어 있지 않아요 (용량 때문에 제외했습니다).
아래 순서대로 실행해주세요. Node.js 18 이상이 설치되어 있어야 합니다.

```bash
cd dokhoogam-app

# 1. 패키지 설치
npm install

# 2. .env 파일에 Postgres 연결 문자열 넣기 (Render 대시보드 > Postgres > Connect
#    > External Database URL 을 복사해서 DATABASE_URL 값에 붙여넣기)

# 3. 데이터베이스 스키마 반영 (최초 1회, 스키마가 바뀔 때마다 다시 실행)
npx prisma db push

# 4. 개발 서버 실행
npm run dev
```

브라우저에서 http://localhost:3000 접속하면 됩니다.

로컬 개발과 배포된 서비스가 같은 Postgres를 공유해도 되고, 필요하면 로컬용
Postgres를 따로 만들어 `.env`만 다르게 설정해도 됩니다.

- 이메일 인증, 비밀번호 재설정
